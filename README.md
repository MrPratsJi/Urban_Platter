# Urban Platter – Full Stack Food Delivery Website 🍴🚀

Urban Platter is a **full-stack food delivery platform** that allows users to browse food items, add them to cart, place orders, and track delivery in real-time.  
It is inspired by popular platforms like **Swiggy** and **Zomato**, but built with a clean, scalable, and customizable architecture. It also has an AI ChatBot 
named **Prata** which helps users to get real-time insights.


## ✨ Features

### 👨‍🍳 User Features
- User Registration & Login (OAuthentication)
- Browse Restaurants & Food Items
- Advanced Search & Filters
- Cart & Checkout System
- Secure Online Payments
- Real-Time Order Tracking
- AI ChatBot - **Prata**

### 🏪 Restaurant Dashboard
- Menu Management (Add, Update, Delete Items)
- Accept / Reject Orders
- Update Order Status
- Delivery Coordination

### 🛠️ Admin Panel
- Manage Users, Restaurants, and Orders
- View Analytics & Reports
- Control Product Listings
- Ensure Smooth Operations


## 🖥️ Tech Stack

### Frontend
- **React.js** – UI development  
- **TailwindCSS** – Modern responsive styling  
- **Context API** – State management  

### Backend
- **Node.js + Express.js** – RESTful APIs  
- **OAuth** – Authentication & Authorization  
- **Razorpay** – Payment Gateway Integration  

### Database
- **MongoDB** – Scalable data storage
